Sources inspected directly for this audit:

- **Original reference**: `Reference/Graduate_Training_Matrix.html` (44,713 lines, single-file vanilla JS app, patched ~40 times — cascade/reassignment resolved to the *final active* version for every item below, not the first definition found).
- **Ventilation Tool** (Etch visual language source): `../ventilation-tool-app/app/globals.css`, `app/layout.tsx`, `components/ventilation/VentilationApp.tsx`, `components/ventilation/ProjectDataPanel.tsx`, `VentilationLoadsPanel.tsx`, `DesignCriteriaPanel.tsx`, `IAQPanel.tsx`, `PrintModal.tsx`, `components/ui/select.tsx`, `combobox.tsx`.

**Visual-verification method**: no browser/screenshot automation is available in this session (confirmed — no Playwright/Puppeteer tool, no such dependency in either project). Per your instruction, this audit and the resulting implementation use **source-level matching only**: exact CSS values, exact markup structure/order, exact wording, extracted directly from source and cross-checked against the current implementation. The "Verification screenshot" column reads "Not captured" throughout — no percentage or pixel-diff claim is made anywhere in this document.

**Headline finding that changes the risk profile of this whole project**: the reference tool has full CRUD (create/edit/delete/sign-off) for CPD entries, meetings/reviews, and baseline tasks — none of which exist in the current app (100% read-only today). I checked the RLS migrations directly: **`cpd_entries`, `meetings`, `candidate_reviews`, and `candidate_baseline_tasks` already have INSERT/UPDATE/DELETE policies** (`supabase/migrations/20260715000900_...sql` lines 405-608, `20260715000300_...sql` lines 282-317). Nothing was ever built to use them. This means most of the missing CRUD in Stage 3 is pure application work — **no migration needed**. The one confirmed exception: `candidates` only has an `organization-admin` UPDATE policy (`20260715000300_...sql:109-114`) — there is **no self-service (candidate) or mentor UPDATE policy**, so a graduate cannot save their own pathway edits today without a new migration. Flagged below; not fixed without your sign-off since section 21 of your instructions prohibits schema changes.
